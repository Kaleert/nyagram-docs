# Введение в Nyagram

Привет! Если ты читаешь это, значит, у тебя есть идея для Telegram-бота, но нет желания писать сотни строк шаблонного кода, разбираться с JSON-парсингом и вручную настраивать `HttpClient`.

**Nyagram** — это современная, легковесная и мощная библиотека для создания Telegram-ботов на Java (Spring Boot), созданная с одной целью: **сделать разработку ботов удовольствием, а не пыткой.**

> 💡 **Философия Nyagram:** Ты пишешь бизнес-логику, а библиотека берет на себя всё остальное: от получения обновлений до валидации аргументов и управления состоянием пользователя.

## Почему именно Nyagram?

Давай честно: писать ботов на "голом" API или устаревших библиотеках — это больно. Бесконечные `if (update.hasMessage() && update.getMessage().hasText())`, ручной разбор аргументов команды `/ban @username reason`... Зачем, если можно проще?

### ✨ Магия аннотаций
Забудь про `switch-case`. В Nyagram ты просто помечаешь метод аннотацией, и он начинает работать.

```java
@BotCommand(value = "/start", description = "Запуск бота")
public class StartCommand {

    @CommandHandler
    public void execute(CommandContext ctx) {
        ctx.reply("Привет! Я работаю на Nyagram 🚀");
    }
}
```

### 🧠 Умные аргументы
Библиотека сама "вытащит" нужные данные из сообщения и передаст их в твой метод. Тебе не нужно парсить строку вручную.

```java
// Команда: /ban @spammer За спам
@CommandHandler("ban")
public void banUser(
    CommandContext ctx, 
    @CommandArgument("user") String username, 
    @CommandArgument("reason") String reason
) {
    // В username уже лежит "@spammer", а в reason — "За спам"
    ctx.reply("Пользователь " + username + " забанен. Причина: " + reason);
}
```

### 🔄 FSM (Машина состояний) из коробки
Нужно сделать пошаговую анкету или сложный диалог? Не нужно придумывать велосипеды с базой данных. Nyagram умеет запоминать, на каком шаге находится пользователь.

### 🛡️ Безопасность и Middleware
Нужно ограничить доступ к админке? Или логировать каждое действие? 
*   `@RateLimit` — защита от спама.
*   `@LevelRequired` — проверка уровня доступа.
*   `Middleware` — вклинивайся в процесс обработки запроса на любом этапе.

## Что под капотом?

Nyagram построена на базе **Spring Boot 3** и **Java 21**. Это значит, что ты получаешь всю мощь экосистемы Spring:
*   Внедрение зависимостей (Dependency Injection).
*   Легкая конфигурация через `application.yml`.
*   Поддержка Redis для хранения сессий (но есть и in-memory режим для старта).
*   Виртуальные потоки (Project Loom) для максимальной производительности.
