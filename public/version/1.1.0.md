## [1.1.0] - 2026-01-19

### 🚀 Added (Новое)
*   **Spring Boot Starter**: Добавлен `AutoConfiguration.imports`. Теперь не нужно вручную прописывать `@ComponentScan` в основном приложении.
*   **HelpGenerator**: Сервис для автоматической генерации справки `/help`. Группирует команды по методам, поддерживает алиасы и скрывает админские команды от обычных пользователей.
*   **Controller-Style Commands**: Поддержка классов-контроллеров. Теперь можно определять несколько команд (`@CommandHandler`) внутри одного класса без аннотации `value` в `@BotCommand`.
*   **Graceful Fallback**: Добавлены дефолтные реализации для `UserLevelProvider`, `BroadcastTargetProvider` и `UserPermissionProvider`. Бот запускается даже без настройки безопасности.
*   **MissingArgumentHandler**: Интерфейс для кастомной обработки ошибок отсутствующих аргументов. По умолчанию выводит красивое сообщение с синтаксисом.
*   **Resilient HTTP Client**: В `NyagramClient` добавлены:
    *   Exponential Backoff (экспоненциальная задержка при ошибках).
    *   Автоматическая обработка `429 Too Many Requests`.
    *   Ретраи при `5xx` ошибках Telegram API.

### 🛠 Changed (Изменено)
*   **CommandRegistry**: Полностью переписана логика регистрации. Улучшен поиск команд (Longest Match First), исправлена работа русских алиасов без слэша.
*   **Конфигурация**: Класс свойств переведен на `@ConfigurationProperties` без `@Component`, чтобы избежать конфликтов имен бинов (`ConflictingBeanDefinitionException`).

### 🐛 Fixed (Исправлено)
*   Исправлена ошибка валидации аргументов, приводящая к молчанию бота.
*   Исправлено кодирование HTML-сущностей в генераторе помощи.
