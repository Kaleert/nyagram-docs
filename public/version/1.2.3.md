# Nyagram 1.2.3

*Дата релиза: 11 октября 2026*

В этом патч-релизе мы сосредоточились на стабильности: исправили критический баг с отправкой инлайн-клавиатур и устранили проблему с автоконфигурацией при запуске бота. Обновление строго рекомендуется всем пользователям ветки `1.2.x`.

## 🐛 Исправления ошибок (Bug Fixes)

*   **Ошибка `400 Bad Request` при отправке Inline-клавиатур**
    Исправлен баг, из-за которого Telegram API отклонял запросы с кнопками, возвращая ошибку `field "force_reply" must be of type Boolean`.
    * **Причина:** Поле `forceReply`, добавленное в `InlineKeyboardMarkup` в недавних обновлениях, сериализовалось в JSON как `null`, если не было явно задано.
    * **Решение:** Для записи `InlineKeyboardMarkup` добавлено строгое правило `@JsonInclude(JsonInclude.Include.NON_NULL)`. Теперь пустые поля корректно игнорируются при сборке запроса.

*   **Сбой при запуске (`UnsatisfiedDependencyException`)**
    Исправлена ошибка старта приложения `No qualifying bean of type 'BaseUrlController' available`, возникавшая, если разработчик не переопределял контроллер базового URL вручную.
    * **Причина:** Использование `@ConditionalOnMissingBean` вместе с `@Component` на классе `DefaultBaseUrlController` работало нестабильно из-за порядка Component Scan в Spring Boot.
    * **Решение:** Дефолтная реализация очищена от системных аннотаций и жестко зарегистрирована как `@Bean` внутри `NyagramAutoConfiguration`. Теперь фреймворк гарантированно предоставляет фоллбэк при любых условиях.

## 🛠 Под капотом (Under the Hood)

*   **Оптимизация сканирования Spring Context:** Удалены избыточные компоненты-заглушки из сканирования. Теперь ядро инициализируется чище и быстрее, полностью полагаясь на централизованную конфигурацию.

## 🚀 Как обновиться?

Обновление не ломает обратную совместимость. Миграция кода **не требуется**.
Просто измените версию в вашем конфигурационном файле:

**Gradle (Groovy):**
```groovy
implementation 'io.github.kaleert:nyagram:1.2.3'
```

**Maven:**
```xml
<dependency>
    <groupId>io.github.kaleert</groupId>
    <artifactId>nyagram</artifactId>
    <version>1.2.3</version>
</dependency>
```
