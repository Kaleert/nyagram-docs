## [1.1.2] - 2026-02-20

### 🛡️ Critical (Критическое)
*   **FSM Text Routing Fix**: Исправлена критическая ошибка в `UpdateProcessor`. Ранее обычные текстовые сообщения (не команды) всегда уходили в `EventDispatcher`, игнорируя активную FSM-сессию. Теперь, если у пользователя есть активное состояние (`state != null`), сообщения принудительно направляются в `CommandDispatcher`, что позволяет `FsmMiddleware` корректно обрабатывать ввод данных (пароли, токены, ответы на вопросы).
*   **Multipart URL Handling**: Исправлен баг в `NyagramClient`, вызывавший `IllegalArgumentException: InputFile has no content` при попытке отправить файл по URL или `file_id`. Клиент теперь корректно различает загрузку физического файла (Stream) и передачу ссылки (String) в multipart-запросах.

### 🐛 Fixed (Исправлено)
*   **VarArgs Resolution**: Исправлен порядок разрешения аргументов в `CommandDispatcherImpl`. Теперь аргументы переменной длины (`String... args`) проверяются до поиска типизированных резолверов, что устраняет ошибку `No resolver found for type: String[]`.
*   **Default Handler Fallback**: `CommandRegistry` теперь корректно возвращает дефолтный обработчик (метод с пустым `@CommandHandler`), если текст сообщения не совпал ни с одной явной командой. Это позволяет обрабатывать произвольный текст в ЛС (например, для поиска).
*   **MessageOrigin Visibility**: Исправлена видимость реализаций интерфейса `MessageOrigin`. Рекорды `MessageOriginUser`, `MessageOriginChat` и др. перенесены внутрь интерфейса и сделаны публичными, что позволяет использовать `instanceof` в прикладном коде.

### 🚀 Added (Новое)
*   **InlineQueryResultAudio**: Добавлен недостающий класс для отправки аудиофайлов через Inline-режим.
*   **Thumbnail Support**: В `InlineQueryResultAudio` добавлено поле `thumbnail_url` для отображения обложек треков в результатах поиска.
*   **ReplyKeyboardRemove**: Добавлен класс для удаления кастомной клавиатуры (`remove_keyboard: true`).

### 🛠 Changed (Изменено)
*   **Update DTO Structure**: Обновлена структура внутренних классов в `Update.java`. Все вложенные классы (`CallbackQuery`, `InlineQuery` и др.) теперь корректно сериализуются и имеют доступные геттеры.
