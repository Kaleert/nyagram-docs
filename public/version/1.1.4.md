## [1.1.4] - 2026-03-11

Это масштабное обновление фреймворка, которое включает в себя глубокую реструктуризацию системы версионирования, внедрение мощного "синтаксического сахара" для разработчиков, ряд критических исправлений производительности и **полную 100% поддержку Telegram Bot API версии 9.5**.

### 🚀 Added (Новое)

*   **Централизованное управление версиями (SSOT)**: 
    *   В корень проекта добавлен файл `package.json`. Теперь он является единым источником истины для версии фреймворка, версии Telegram API и ссылок на документацию.
    *   Сборка Gradle, генератор документации (`DocGenerator`) и бейджи в `Readme.md` теперь синхронизируются с `package.json` автоматически.
*   **NyagramUpdateChecker (Update Notifier)**:
    *   Добавлен встроенный клиент-серверный чекер обновлений. При запуске (пост-инициализации) бот асинхронно проверяет наличие новой версии фреймворка в репозитории на GitHub.
    *   В случае доступности новой версии, в лог выводится красивое предупреждение со ссылкой на changelog.
    *   Функцию можно отключить в конфигурации: `nyagram.check-updates=false`.
*   **Полная поддержка Telegram Bot API 9.5**:
    *   Добавлены все новые объекты и поля, появившиеся в API 9.0 – 9.5.
    *   **Gifts (Подарки)**: Добавлены DTO `Gift`, `Gifts` и методы `SendGift`, `GetAvailableGifts`.
    *   **Verification**: Добавлены методы для верификации пользователей и чатов от лица организации: `VerifyUser`, `VerifyChat`, `RemoveUserVerification`, `RemoveChatVerification`.
    *   **CopyTextButton**: В `InlineKeyboardButton` добавлена поддержка кнопок копирования текста (введены в API 9.5). В `InlineKeyboardBuilder` добавлен удобный метод `.copyButton("Текст на кнопке", "Текст для копирования")`.
    *   **Message Effects**: Во все методы отправки сообщений добавлено поле `message_effect_id` для запуска полноэкранных анимаций (огонь, сердечки и т.д.). В билдеры добавлен хелпер `.withEffect(effectId)`.
    *   **Paid Media**: Реализованы `InputPaidMedia` (для отправки) и `PaidMedia` (для получения) платных фотографий и видео за Telegram Stars.
    *   **Star Subscriptions**: Добавлена поддержка платных подписок в `CreateInvoiceLink`, `CreateChatInviteLink`, `EditChatInviteLink` и `ChatInviteLink`.
    *   **Batch Operations**: Добавлены методы для пакетной работы с сообщениями: `DeleteMessages`, `ForwardMessages`, `CopyMessages`.
    *   **Caption Position**: В методы отправки медиа добавлено поле `show_caption_above_media`. Добавлен метод билдера `.captionAbove()`.
    *   **Business Bots & Direct Messages**: Обновлен объект `Message`. Добавлены поля `is_direct_message`, `sender_business_bot`, `business_connection_id`, `is_suggested` и другие. Добавлен объект `BusinessOpeningHours`.
    *   **Tags**: Обновлены объекты участников чата (`ChatMemberMember`, `ChatMemberRestricted`) и прав (`ChatPermissions`). Добавлен метод `SetChatMemberTag`.
    *   **Message Entity**: Добавлен новый тип сущности `date_time` (API 9.5) и соответствующие поля `unix_time`, `date_time_format`.
    *   **Keyboard Styling**: В кнопки добавлены поля `icon_custom_emoji_id` и `style` для изменения их цвета и добавления иконок (API 9.4).
    *   **Refunds & Rating**: Добавлены `RefundedPayment` и `UserRating`.
*   **EditMessageCaption**: Внедрен метод `EditMessageCaption` для удобного редактирования подписей к медиафайлам без необходимости переотправлять всё медиа целиком.
*   **EditMessageReplyMarkup**: Добавлен метод для быстрого обновления только инлайн-клавиатуры сообщения.
*   **FSM Auto-Persistence**: 
    *   Существенное улучшение машины состояний! Класс `UserSession` теперь оборачивается в `ManagedUserSession`. 
    *   Любые изменения сессии (вызовы `session.putData()` или `session.setState()`) теперь **автоматически** синхронизируются с хранилищем (Redis/Database). Больше не нужно вручную вызывать `sessionManager.saveSession()`.
*   **"Nyagram Sugar" (Синтаксический сахар)**:
    *   В `CommandContext` добавлен метод `react(String emoji)` для быстрой установки реакции на сообщение пользователя.
    *   В `CommandContext` добавлен метод `answerCallback(String text, boolean showAlert)` для удобного ответа на инлайн-кнопки.
    *   В `CommandContext` добавлен метод `deleteMessageQuietly(Integer messageId)` для безопасного удаления сообщений с перехватом исключений (если сообщение уже удалено).
    *   В `CommandContext` добавлены методы `editMessage(...)` для быстрого редактирования сообщений напрямую в callback-обработчиках.
    *   В `Message` добавлены удобные геттеры `getPrimaryFileId()` и `getPrimaryMediaType()` для избавления от каскадов `if-else` при работе с разными типами медиа.
    *   Добавлено перечисление `ChatAction` (вместо использования сырых строк вроде "typing"), обновлен `ChatActionService`.
*   **Встроенная поддержка i18n (Локализация)**:
    *   Во фреймворк добавлен интерфейс `LocaleResolver`. 
    *   В `CommandContext` внедрен метод `.translate("key")`. Если разработчик реализует `LocaleResolver`, фреймворк будет автоматически определять локаль текущего пользователя и переводить строки "на лету" без необходимости ручного прокидывания локали.

### 🧪 Testing & Stability (Тестирование)
*   **Unit Tests Infrastructure**: Внедрено базовое покрытие юнит-тестами ключевых компонентов ядра (с использованием JUnit 5 и Mockito).
*   Написаны тесты для `UpdateProcessor`, `SessionManager`, `ValidationMiddleware` и механизмов парсинга аргументов. Теперь любые изменения в ядре автоматически проверяются на обратную совместимость при сборке проекта (`./gradlew build`), гарантируя стабильность работы ботов после обновлений фреймворка.

### 🛠 Changed (Изменено)

*   **ChatActionService Optimization**: Сервис отправки статусов (например, "печатает...") полностью переписан. Вместо создания сырых `Thread` теперь используется управляемый `ScheduledExecutorService`, что устраняет возможные утечки потоков при высоких нагрузках.
*   **Project Structure**: Произведен глобальный рефакторинг пакетов и импортов. Все внутренние исключения перенесены в выделенный пакет `com.kaleert.nyagram.exceptions`.
*   **DocGenerator Update**: Генератор документации адаптирован под чтение версии проекта напрямую из `package.json` (с использованием `ObjectMapper`).
*   **Universal BroadcastManager**: Сервис рассылок переведен на использование `CopyMessage` в методе `broadcastMessage(...)`. Теперь рассылка поддерживает любые типы контента (фото, видео, кружочки, альбомы). Улучшена синхронизация потоков через `Phaser`.

### 🛡️ Critical (Критическое)

*   **FileService OOM Fix**: Исправлена критическая уязвимость, приводившая к `OutOfMemoryError` при скачивании больших файлов (видео, документы). Теперь `FileService` использует потоковую запись на диск напрямую через `InputStream` и `Files.copy`, минуя загрузку всего массива байт в оперативную память.
*   **LocaleService Thread Safety**: Устранен небезопасный unchecked cast и использование устаревшего `new Locale(String)`. Теперь загрузка YAML-файлов локализации работает строго через `Locale.forLanguageTag()`.
