# Nyagram 1.2.0: UI Engine, Сцены и Telegram Bot API 10.0

Nyagram 1.2.0 — это масштабное обновление, которое выводит архитектуру разработки ботов на совершенно новый уровень. Мы добавили декларативные меню, пошаговые сценарии (Wizard), динамическую маршрутизацию Middleware и, конечно же, полную поддержку долгожданного Telegram Bot API 10.0.

---

## 🌟 Главные нововведения

### 1. Декларативные интерфейсы (UI Engine)
Забудьте о ручном создании `InlineKeyboardBuilder` в каждом контроллере. Теперь вы можете описывать меню и привязывать кнопки к методам с помощью аннотаций `@Menu` и `@MenuButton`. Nyagram сам сгенерирует клавиатуру и настроит маршрутизацию коллбэков!

```java
@Menu(id = "settings_menu", text = "⚙️ Настройки")
public class SettingsMenu {

    @MenuButton(row = 0, text = "🇺🇸 Сменить язык")
    public void changeLanguage(CommandContext ctx) {
        ctx.answerCallback("Язык изменен", false);
    }

    @MenuButton(row = 1, text = "⬅️ Назад", style = "danger")
    public void back(CommandContext ctx) {
        // Логика возврата
    }
}
```
*Для вызова меню из любого места в коде используйте `uiRegistry.getKeyboard("settings_menu")`.*

### 2. Сценарный движок (Wizard API)
В дополнение к стандартной FSM (где состояния задаются строками), были добавлены **Сцены**. Это идеальное решение для линейных диалогов (опросов, форм регистрации, создания заказов).

Просто наследуйте класс от `Wizard` и пронумеруйте шаги аннотацией `@Step`:

```java
@Scene("ORDER_PIZZA")
public class OrderWizard extends Wizard {

    @Step(1)
    public void askSize(CommandContext ctx) {
        ctx.reply("Какой размер пиццы вы хотите?");
        nextStep(ctx, 2); // Переход к шагу 2
    }

    @Step(2)
    public void askAddress(CommandContext ctx, @SessionData("size") String size) {
        ctx.reply("Отлично! Пицца размера " + size + ". Куда везти?");
        finish(ctx); // Завершение сценария и очистка сессии
    }
}
```

### 3. Маршрутизация Middleware (Middleware Routing)
Раньше Middleware срабатывали абсолютно для всех входящих апдейтов. Теперь вы можете ограничить их работу конкретными командами, используя Ant-паттерны в аннотации `@MiddlewareRoute`.

```java
@MiddlewareRoute("/admin/**") // Сработает только для команд, начинающихся на /admin
@Component
public class AdminSecurityMiddleware implements Middleware {
    // ...
}
```

### 4. Динамическое переключение URL (BaseUrlController)
Для ботов, работающих в сложных сетевых условиях или через прокси-шлюзы, мы добавили интерфейс `BaseUrlController`. Он позволяет менять базовый URL API Telegram "на лету", не перезапуская бота. Если текущий шлюз упадет, фреймворк вызовет метод `reportError`, и вы сможете переключить трафик на резервный сервер.

## 🤖 Поддержка Telegram Bot API 10.0

Nyagram полностью обновлен для работы с последними изменениями платформы Telegram.

*   ⭐️ **Платные рассылки (Paid Broadcasts):** Теперь бот может отправить сообщение даже тем пользователям, которые его заблокировали, потратив на это Telegram Stars (0.1 звезды за сообщение). Добавлено поле `allow_paid_broadcast` и удобный метод `.paidBroadcast()` во все классы `Send...` (`SendMessage`, `SendPhoto`, `CopyMessage` и т.д.).
*   👥 **Гостевой режим (Guest Mode):** Полная поддержка Mini Apps Guest Mode. Добавлены объекты `SentGuestMessage`, `AnswerGuestQuery`, а в `Message` появились поля `guest_bot_caller_user` и `guest_query_id`.
*   🖼 **Live Photos & Poll Media:** Добавлена поддержка "живых фото" (объект `LivePhoto`). В методы отправки опросов добавлены поля для прикрепления медиа (`media` и `explanation_media`).
*   ❌ **Удаление реакций:** Добавлены методы `DeleteAllMessageReactions` и `DeleteMessageReaction` (позволяет ботам-модераторам удалять реакции конкретных пользователей).
*   🎁 **Подарки (Gifts):** В объект `Message` добавлено поле `gift` (объект `GiftInfo`), позволяющее отслеживать подарки, отправленные пользователями в чат.

## 🐛 Исправления ошибок (Bug Fixes)

*   **[Критично] Баг Multipart-сериализации:** Исправлена редкая ошибка, при которой методы `editMessageMedia` и `sendMediaGroup` могли возвращать ошибку `media not found`. Ранее Jackson-сериализатор вызывал двойную генерацию UUID для `InputStream/File`, из-за чего имена файлов в JSON и в Multipart-теле не совпадали. Защищено аннотацией `@JsonIgnore`.
*   **Сборка Javadoc:** Исправлена ошибка компиляции Javadoc, вызванная использованием специфичной аннотации Lombok `@Setter(onMethod_ = @Autowired)` в базовом классе `Wizard`.

## ⚡️ Обновление до 1.2.0

В версии 1.2.0 нет критических изменений, ломающих обратную совместимость (Breaking Changes). Чтобы обновиться, просто измените версию в вашем сборщике.

**Gradle:**
```groovy
implementation 'io.github.kaleert:nyagram:1.2.0'
```

**Maven:**
```xml
<dependency>
    <groupId>io.github.kaleert</groupId>
    <artifactId>nyagram</artifactId>
    <version>1.2.0</version>
</dependency>
```
