# Nyagram 1.2.4: Telegram Bot API 10.4, Widgets и новые возможности

*Telegram Bot API 10.4 | Дата релиза: 10 ноября 2026*

Nyagram 1.2.4 — обновление с поддержкой новых возможностей Telegram Bot API, включая HTML-виджеты, расширенные Rich Messages, объекты TON Wallet и новые методы работы с подарками.

Основное внимание уделено расширению моделей Telegram, поддержке новых запросов и сохранению привычного API библиотеки.

---

## 🚀 Главные нововведения

### 1. 🧩 Telegram Widgets

Telegram Bot API 10.4 представил виджеты — интерактивные HTML-компоненты, которые можно отправлять непосредственно в сообщениях.

В Nyagram добавлены классы для работы с виджетами и новые методы:

- `SendWidget` — отправка HTML-виджета в чат.
- `SendSharedWidget` — повторная отправка ранее опубликованного общего виджета.
- `EditSharedWidgetData` — изменение публичных данных общего виджета.
- `EditMessageWidgetData` — обновление данных виджета в сообщении.
- `WidgetLimits` — проверка допустимых размеров данных.

**Ограничения Telegram:** в production-среде отправка виджетов пока доступна только в личных чатах. Отправленные виджеты автоматически защищены от пересылки.

### 2. 📝 Rich Messages и форматированный текст

Расширены модели для представления форматированного содержимого Telegram.

- `InputRichMessage` поддерживает создание сообщений из HTML, Markdown и структурированных блоков.
- `RichTextValue` предоставляет модель форматированного текста и обработку JSON-представления.
- `RichTextTonAddress` добавляет поддержку TON-адресов внутри Rich Messages.

Это позволяет работать со сложным содержимым через типизированные Java-объекты, а не собирать JSON вручную.

### 3. 💎 TON Wallet

Telegram Bot API 10.4 добавил новые объекты TON Wallet, включая карточки кошельков, NFT и уведомления о переводах.

В рамках обновления расширены соответствующие модели Telegram, в том числе `ChatFullInfo`.

### 4. 🎁 Telegram Gifts

Добавлены новые методы работы с подарками:

- `GetUniqueGift` — получение информации об уникальном подарке по его имени.
- `DeleteBusinessAccountGift` — удаление обычного подарка, принадлежащего управляемому бизнес-аккаунту.

### 5. 💬 Расширение объектов Telegram

Обновлены модели и параметры запросов для новых возможностей Bot API 10.4.

Изменения затрагивают сообщения, информацию о чатах, права пользователей и новые типы содержимого Telegram.

## 🔄 Обновление до 1.2.4

После публикации новой версии достаточно обновить зависимость проекта.

**Gradle (Groovy):**

```groovy
implementation 'io.github.kaleert:nyagram:1.2.4'
```

**Maven:**

```xml
<dependency>
    <groupId>io.github.kaleert</groupId>
    <artifactId>nyagram</artifactId>
    <version>1.2.4</version>
</dependency>
```

> **Примечание:** перед обновлением рекомендуется проверить использование изменённых моделей Telegram и устаревших конструкторов. Окончательный перечень изменений совместимости будет подтверждён перед публикацией.
