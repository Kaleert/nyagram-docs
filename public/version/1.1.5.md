# 🚀 Что нового в Nyagram 1.1.5? [05.05.2026]

## 1. 🛡 Встроенная поддержка динамических прокси (SOCKS5 / HTTP)

Теперь Nyagram позволяет маршрутизировать запросы к Telegram API через
прокси-серверы, причем делать это динамически для каждого отдельного
запроса. Это критически важно для работы ботов в регионах с блокировками.

Вам больше не нужно настраивать прокси глобально на уровне JVM. Достаточно
реализовать интерфейс NyagramProxyProvider:

```java
@Component
public class MyProxyProvider implements NyagramProxyProvider {
    
    @Override
    public NyagramProxy getProxy() {
        // Вы можете брать прокси из БД, ротировать их или возвращать статический
        return NyagramProxy.socks("proxy.example.com", 1080, "user", "pass");
    }

    @Override
    public void onProxyError(NyagramProxy proxy, Throwable ex) {
        // Срабатывает, если прокси отвалился (Таймаут, Connection Reset)
        // Идеальное место, чтобы удалить мертвый прокси из пула
        proxyPool.remove(proxy);
    }
}
```

Фреймворк автоматически применит прокси к HTTP-клиенту, поллеру (Long Polling) и
сервису скачивания файлов (FileService).

## 2. ⚡ Поддержка Telegram Bot API 9.6

Nyagram 1.1.5 полностью адаптирован под последние изменения Telegram:

  - Массовые действия с сообщениями: Добавлены методы CopyMessages,
    ForwardMessages и DeleteMessages (позволяют обрабатывать до 100 сообщений за
    один API-вызов).
  - Управляемые боты (Managed Bots): Полная обвязка для создания и управления
    ботами через Mini Apps:
      - Методы: GetManagedBotToken, ReplaceManagedBotToken,
        SavePreparedKeyboardButton.
      - Типы: ManagedBotCreated, ManagedBotUpdated.
      - Кнопки: KeyboardButtonRequestManagedBot.
  - Reply Parameters: Устаревшие поля reply_to_message_id и
    allow_sending_without_reply помечены аннотацией @Deprecated. Теперь для
    ответов на сообщения (особенно на варианты в опросах) используется
    новый объект ReplyParameters.
  - Локальный Bot API Сервер: Добавлены методы LogOut и Close для безопасного
    переноса бота с облака Telegram на локальный инстанс.
  - Кастомные стили кнопок: В InlineKeyboardButton и KeyboardButton добавлено
    поле style (primary, success, danger).

## 3. 🧠 Умное редактирование (Smart Edit)

Раньше при редактировании сообщений с кнопками вам приходилось вручную
проверять, содержит ли сообщение картинку (EditMessageCaption) или это
просто текст (EditMessageText).

Теперь CommandContext делает это за вас!

```java
// Nyagram сам проверит, есть ли в текущем сообщении медиафайл, 
// и вызовет нужный метод (EditMessageText или EditMessageCaption)
ctx.editMessage("Новый текст!", newKeyboard);
```

Также добавлен удобный метод для замены самой картинки/видео "на лету":

```java
// Заменяем картинку в текущем сообщении
InputMedia newPhoto = InputMediaPhoto.builder().media("file_id_123").build();
ctx.editMedia(newPhoto, newKeyboard);
```

## 4. 📻 Гибридный Broadcast API

Сервис рассылок BroadcastManager стал еще умнее. Метод runAdvancedBroadcastLoop
теперь использует гибридный подход:

  - Если к рассылаемому сообщению не прикреплена новая клавиатура, используется
    ForwardMessage (работает быстрее и сохраняет оригинальный вид поста).
  - Если клавиатура передана, используется CopyMessage (создает клон поста с
    вашими кнопками).

## 5. 🛠 Исправления багов и улучшения ядра

  - Фикс парсинга флагов (@Flag): Исправлен критический баг в
    CommandDispatcherImpl. Ранее, если флаг (например, -f) стоял в середине
    текста, он ломал позиционный парсинг остальных аргументов
    (@CommandArgument). Теперь флаги извлекаются из списка токенов до начала
    обработки основных параметров.
  - Новые хелперы в Message:
      - getPrimaryFileId() — быстро получить ID главного медиафайла в сообщении
        (неважно, фото это, видео или войс).
      - getPrimaryMediaType() — получить тип медиа строкой (photo, video, voice
        и т.д.).
      - isCaptionAbove() — проверяет, находится ли текст над картинкой (новая
        фича Telegram).
  - Тихое удаление: В CommandContext добавлен метод deleteMessageQuietly(id). Он
    пытается удалить сообщение, но если оно уже удалено или слишком старое, он
    молча проигнорирует исключение, не засоряя логи.
  - Изоляция Locale: Добавлен интерфейс LocaleResolver, позволяющий определять
    язык пользователя "на лету" из базы данных для корректной работы
    ctx.translate().

### ⚠️ Deprecation Notices (Что устарело)

  - В методах SendPhoto, SendMessage, SendVideo и др. поля reply_to_message_id и
    allow_sending_without_reply объявлены устаревшими. Пожалуйста, мигрируйте на
    использование reply_parameters.
  - Метод BroadcastManager.runBroadcastLoop(text) устарел в пользу продвинутой
    гибридной отправки broadcastMessage().
