# Nyagram v1.2.2

*Релиз: Август 2026 | Telegram Bot API 10.3*

Обновление включает полную поддержку Telegram Bot API 10.3, новые методы для работы с подписками (Telegram Stars), черновиками сообщений и бизнес-ботами, а также исправление критической ошибки блокировки потоков при Rate Limit.

### 🚀 Added (Новое)
*   **Telegram Bot API 10.3**:
    *   Поддержка эфемерных (исчезающих) сообщений. Поле `ephemeralMessageParameters` интегрировано в 13 поддерживаемых методов отправки (`SendMessage`, `SendPhoto` и др.).
    *   Поддержка неактивных кнопок (`disabled` в `InlineKeyboardButton`).
    *   Поддержка принудительного ответа на инлайн-кнопки (`force_reply` в клавиатурах).
    *   Права администратора на отправку приветственных сообщений (`can_send_welcome_messages`).
*   **Telegram Subscriptions (Подписки)**: Добавлен DTO `BotSubscriptionUpdated` и соответствующее событие в `Update` для отслеживания платных подписок пользователей на бота.
*   **Prepared Inline Messages**: Добавлен метод `SavePreparedInlineMessage` для генерации инлайн-сообщений из Mini Apps.
*   **Черновики (Drafts)**: Добавлен метод `SendMessageDraft` для установки и очистки текста в строке ввода пользователя.
*   **Telegram Business**: Добавлены методы `GetBusinessConnection`, `GetUserPersonalChatMessages` и DTO `BotAccessSettings`.
*   **WebApp**: Добавлен метод `AnswerWebAppQuery` для ответа инлайн-сообщением на запросы из Mini Apps.
*   **Chat Boosts**: Добавлен метод `GetUserChatBoosts` для получения информации о бустах конкретного пользователя.
*   **Leaderboards**: Добавлен метод `GetGameHighScores` для получения таблицы рекордов игр.
*   **Custom Emojis**: Добавлены методы `GetCustomEmojiStickers` и `GetForumTopicIconStickers`.
*   **Chat Administration**: 
    *   Добавлены методы `GetChat` и `GetChatAdministrators`.
    *   Добавлены методы блокировки каналов в группах: `BanChatSenderChat`, `UnbanChatSenderChat`.
    *   Добавлены методы управления заявками на вступление: `ApproveChatJoinRequest`, `DeclineChatJoinRequest`.
    *   Добавлены методы управления главным топиком (General) на форумах.
    *   Методы получения настроек бота: `GetChatMenuButton`, `GetMyDefaultAdministratorRights` и `SetMyDefaultAdministratorRights`.
    *   Метод отмены/возобновления подписки: `EditUserStarSubscription`.
*   **Sugar API (Хелперы)**:
    *   В `CommandContext` добавлены методы: `setDraft`, `clearDraft`, `getBusinessConnection`, `forwardTo`, `copyTo`.
    *   В `Update` добавлены проверки: `isSubscriptionUpdate`, `isBusinessConnection`, `isBusinessMessage`.

### 🛡️ Critical (Критическое)
*   **Rate Limit Thread Blocking Fix**: Исправлена архитектурная ошибка в `NyagramClient`. При получении ответа `429 Too Many Requests` поток пула (`NyagramExecutor`) уходил в синхронный `Thread.sleep()`, блокируя обработку сообщений других пользователей в том же шарде. Механизм заменен на асинхронный отложенный перезапуск через `CompletableFuture.delayedExecutor`.
*   **Poller Error Handling**: Устранен мертвый код в `NyagramPoller`. Ошибки API (401, 404, 409, 429) теперь корректно перехватываются и логируются в блоке `HttpClientErrorException`.

### 🛠 Changed (Изменено)
*   Метод `reply(...)` в `CommandContext` переведен на использование современного объекта `ReplyParameters`. Устаревшее поле `reply_to_message_id` больше не применяется.
